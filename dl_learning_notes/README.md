这里想先着重说一下pytorch很重要的类型：tensor和variable。tensor其实类似于numpy的nparray（pytorch自称神经网络届的numpy），但是在表达形式上有点区别，比如：
nparray不用逗号分隔，tensor元素就是逗号分隔；nparray可以用dot（），但是tensor几乎不能（在高版本中，对于一维数组可以）
一般来说，从底层上来讲，如果处理的是数字数据（先不论来源），一般都用tensor储存对应的数字模型，接下来就会干一件事，把tensor放到variable中。
为什么？
因为variable有一个很强强的功能：绘制并记录计算图（computational graph）。有了这个计算图，计算机才能了解到这次的计算是怎么发生的，哪一级函数对应什么样的梯度。换言之，计算图是将所有的计算步骤 (节点) 都连接起来, 最后进行误差反向传递的时候, 一次性将所有 variable 里面的修改幅度 (梯度) 都计算出来, 而 tensor（古早版本）就没有这个能力啦。
不过要特别强调的是，现代的pytorch中tensor已经把variable合并了。驻波现在所说的，其实是借用老版本中有的概念把这个问题说的更清楚。现在的tensor已经可以在参数列表中写requires_grad=True，就是说记录计算图的意思。
这个是优化器，乃至整个神经网络训练的基石依赖。因为优化器严重依赖梯度的计算，所以在向前传输过程中保存计算路径，在反向传播过程中保存对应梯度，再让优化器利用是很重要的。
现代nn.Moudle中也有一个关键参数Parameter，这个参数就是告诉网络模型：我是一个网络模型。这样子，pytorch才会把他们放到模型参数里面，也才具有被更新的能力。
对于几个概念的学习：

优化器
优化器是用来根据梯度计算结果更新模型参数的工具，经常利用optimizer变量进行存储。这算是一种约定俗成。在更新参数时，常调用optimizer.step()。
在这里我想介绍一下几个比较经典的优化器，并解释一下为什么最后我会选择Adam。
优化器本质上其实就是根据反向传播得到的梯度grad，对网络中的参数进行更新。因为梯度代表的是loss增长最快的方向，所以参数更新的时候会朝梯度的反方向移动，也就是让loss减小的方向。因此，优化器本质上就是在想办法：如何更稳定、更快速地找到loss更小的位置。
最基础的优化器就是SGD（随机梯度下降）。它每次只使用一个样本进行参数更新。比如我这次的数据集一共有1298张图片，那么一个epoch理论上就需要更新1298次参数。这样做的优点是更新非常细致，而且由于每次数据都不同，它在局部最小值附近有一定概率跳出去，不容易彻底卡死。但是缺点也很明显，因为每次只看一个样本，所以梯度波动会非常大，训练过程容易震荡，稳定性不够好。
要特别注意的是，文中经典SGD指单样本更新，现代深度学习中通常采用Mini-Batch SGD。
与之对应的就是BGD（批量梯度下降）。它会一次性使用整个数据集进行梯度计算，然后再统一更新参数。这样做的梯度方向会更加稳定，但问题也很明显：计算量太大，速度很慢，而且GPU很多时间都在等待，利用率并不高。对于深度学习这种数据量较大的任务来说，通常不太适合。
于是就出现了MBGD（Mini-Batch Gradient Descent），也就是小批量梯度下降。它相当于把整个训练集拆成很多个batch，每次只用一个batch的数据进行训练。这样既能够减少SGD单样本更新带来的剧烈波动，也不会像BGD一样一次性计算全部数据导致速度过慢。在现代深度学习中，MBGD其实已经成为最主流的训练方式。比如这次我设置batch size为32，也就是每次同时计算32张图像，再进行一次参数更新。这样GPU利用率会比较合理，同时训练稳定性和速度也能达到一个平衡。上述内容其实都是经典版本，现代pytorch中的例如SGD已经融合了Momentum，Weight Deca这些算法和参数，其实挺全面的。
不过，上面这些其实更多是“梯度下降方式”的区别。随着深度学习的发展，人们又开始思考：能不能让学习率本身也变得更加智能？
于是就出现了Ada系列优化器。
Adagrad是比较经典的一种。它会记录历史梯度的信息，然后自动调整每个参数对应的学习率。简单来说，如果某个参数过去更新很多次，那么后面它的学习率就会慢慢减小；如果某个参数更新较少，那么学习率会相对大一些。这样做对于稀疏数据或者参数差异较大的场景会比较有效，因为它能够自动适应不同参数的变化情况。
但Adagrad也有一个很明显的问题。由于它会不断累计历史梯度，所以学习率会越来越小。训练前期下降很快，但到后期可能学习率已经小到几乎无法继续更新，容易提前收敛，直接杀死训练。
于是后来又有人提出了Adadelta和RMSprop等优化器。Adadelta对历史梯度进行了在时间传播方向上的增强处理。也就是说，最近的梯度影响更大，而很久之前的梯度影响会逐渐减弱。这样学习率就不会一直无限下降，而是更加关注最近一段时间的训练状态。RMSprop则进一步利用梯度平方的均值来调整学习率，更适合处理非平稳目标，在RNN等网络中应用较多。它本质上也是一种自适应学习率的思想。
不过，这些优化器虽然已经能够动态调整学习率，但很多时候仍然比较依赖初始学习率的设置。如果学习率选得特别离谱，训练依旧可能不稳定。
后来出现了Adam。Adam可以理解为Momentum和RMSprop的一种结合。它不仅会记录梯度的平方信息（二阶矩估计），还会记录梯度本身的变化趋势（一阶矩估计）。这样，它既能够像Momentum一样保持一定“惯性”，减少震荡；又能够像RMSprop一样动态调整不同参数的学习率。
也正因为如此，Adam对学习率没有那么敏感。并不是说它不需要调学习率，而是它本身已经具备了一部分自动调节学习率的能力，因此对于新手来说会更加友好。在数据量不是特别大的情况下，Adam通常能够更快收敛，也更容易训练出效果比较稳定的模型。
哦忘了介绍Momentum了。这其实叫做动量梯度下降算法。顾名思义，这其实是模仿物理学动量的一种类似物理模型。简单来说，他有一项系数lamda。这个系数就是为了在一定程度上继承之前的方向与速度，这样在遇到局部异常值的时候就不容易被带偏。不过这个有一个特性类似于adadelta，就是对较近的速度继承比重更大。
不过，Adam虽然收敛快，但有时候泛化能力未必比SGD更强。有一些大型任务在训练后期会重新切换回SGD进行微调。所以不同优化器其实并没有绝对的好坏之分，更多还是取决于任务本身、数据规模以及训练目标以及要达成的效果。这次训练量不算大，所以我还是采用了adam。在训练数据中可以看到，对于train2,效果没有那么好。所以应该是adam模型的一些问题。之后我会再去试一下SGD之类的，估计也会提交到这个仓库里，可以之后想起来的话回来瞄一眼。这周太忙了，周五要考模电，忙着复习，考完之后这个周末大概就会去搞了。
优化器内部的一些公式我就把他列在下面了：
SGD
θ = θ - η * ∇J(θ)  θ：模型参数  η：学习率；∇J(θ)：loss对参数θ的梯度    老朋友了，这个在机器学习里面就经常见了。
Momentum
v_t = β * v_(t-1) + η * ∇J(θ)    看成动量定理，给这个正在探索的“小球”附加一定的物理属性
θ = θ - v_t    v_t：当前动量；β：动量系数；η：学习率
Adagrad
G_t = G_(t-1) + (∇J(θ))²
θ = θ - η / sqrt(G_t + ε) * ∇J(θ)   adam最后一步疑似从这里学来的，母鸡
G_t：历史梯度平方累加；ε：防止分母为 0
Adadelta
E[g^2]t = ρE[g^2](t-1) + (1-ρ)g_t^2
θ = θ - η / sqrt(E[g^2]_t + ε) * g_t   这个和rmsprop有一点关系，把ρ取成0.5就类似了
ρ：衰减系数；g_t：当前梯度
Adam
一阶矩估计：
m_t = β1 * m_(t-1) + (1-β1) * g_t 这一步关心的是过去累积下来的梯度的方向，类似于惯性，这个就是Momentum的体现
二阶矩估计：
v_t = β2 * v_(t-1) + (1-β2) * g_t^2 这一步就是在记录“速度”，尤其是基本只关心速度的大小，可以用来调整学习率大小
当然，学习率本身并没有变，变的是这个v_t系数本身。如果最近下降的太快了，由于学习率除以这个数，反而会让步长变短。
偏差修正：
m̂_t = m_t / (1-β1^t)  由于一开始这个系数非常小，所以用一个偏差修正来狠狠纠正，当t也就是次数上去之后，这个纠正的程度可以下来一点
v̂_t = v_t / (1-β2^t)  这个同理
参数更新：
θ = θ - η * m̂_t / (sqrt(v̂_t) + ε)   开平方就是因为g_t这个系数一直是平方累加的，一般就关注大小，所以丢掉符号之后不能让他太失真。
m_t：梯度一阶矩估计；v_t：梯度二阶矩估计；β1：一阶矩衰减系数；β2：二阶矩衰减系数；η：学习率；ε：防止分母为 0

要讲清楚这一部分的内容，首先要理解什么是泛化。
我们期望机器能做到的事情：学习一些数据，掌握一些特征，找出一些依据，识别一些类别，往里豪往里豪（）其实是希望机器根据我们给出的训练集学习到这一个类别的物品的特征，然后根据特征进行一些工作,比如分类、语义分割等等。但是，鉴于可能存在的同类型物品的存在形式及其的大（打个比方，就算是一张8*8 256色rgb色图 ，如果每个像素可以取256个灰度值中的一个 都有256^64的可能性 让计算机全部学习是完全不可能的） 所以必须让计算机有一种能力：通过数据集来学习一类事物的特征，然后根据这些特征在之后的过程中真切的识别出同类别实物。
这个目标里面，让机器通过之前有的特征去识别新的现实中的物品到底是不是这个类别的功能，就是泛化。
泛化是机器学习的基本问题，许多数学家和理论家毕生致力于描述这一现象的形式理论。训练的时候，我们比较关心的是模型在训练集上的loss越来越小，但是在现实生活当中，我们真正关心的是在现实当中的新图片还能不能分对。而这个在现实当中的真实的错误率，其实就是我们所说的泛化误差。但是如上文所说，我们现实当中的数据量是非常大的，所以说，在确定了训练的模型之后，我们只能够在训练集数据集这里面做文章。于是，我们真正只能计算的其实只有训练误差。那这个去假使训练误差，它的误差比较低，准确率比较高。但是，因为训练误差不等于泛化误差，所以模型  可能  只是把我们训练集当中的特征给记住了，而并没有真正理解我们训练集到底是什么东西，并没有提炼出一个能够很通用、很泛化在现实当中使用的特征。
根据同名定理，也就是格里文科和坎特利定理，这个定理它告诉我们，如果我们把训练集的数据不断增大，样本数量不断增加的情况下，训练集上的统计结果会越来越接近真实总体的统计结果。换句话来说，也就是训练误差会慢慢逼近泛化误差，也就是训练出来的模型会越来越能够接近真实世界的情况。该定理说明，在满足一定条件时，随着样本数量增加，经验分布会逐渐逼近真实分布。分布与数据量还有模型复杂程度有关。同时要注意，这个数据最好是随机采样的，不要违背独立同分布原则（举个例子，永远不要把在大学生当中收集到的人脸验证信息，用来泛化用于识别老年人的人脸验证信息）。
我们要做的任务就是让这个训练误差尽可能快、尽可能好地逼近泛化误差，从而让我们能够更好地估计这个模型的效用。在深度学习中，由于适用环境的不同和算力的不同，我们通常会根据真实的需求来选择不同的模型。这个模型有可能是简单的模型，它需要的数据量对应的应该会多一些，也有可能是复杂的模型，它的数据量可能没那么多，他对同样数量的数据本身的解释会更好，但是它的泛化能力也有可能会更差（因为参数变多了，机器对这些数据更有可能以复杂模型产生了过拟合）。
那既然知道了训练误差会逼近泛化误差，我们现在就要对训练集做一些调整。原则上在我们确定所有的超参数，也就是参数调好之前，我们是不希望用到测试机的。如果说我们在调参和模型选择过程当中用到了测试集，那么假使我们过拟合了测试数据，那麻烦就很大了，因为这样在之后我们建立完整个模型之后，我们是没有太多的办法评估这个模型它到底是什么样的。而且在工程应用当中，我们理想情况下只使用测试数据几次，以评估最好的模型或者比较模型效果，但是实际情况就是，我们很难获取到如此多的数据量来支持我们每一次都用不同的测试集。但是我们又不能仅仅依靠训练数据，如果说我们只靠训练数据的话，也没有办法进行模型评判，没有办法估计训练数据的泛化误差。所以这就出现了一个更聪明的做法，我们可以再多划分一个数据集，叫验证数据集，同时也叫验证集。但是现实当中的情况就是验证数据和测试数据的边界比较模糊，所以说有待加强划分的精度。
当我们得到的数据就是很少的时候，我们怎么办呢？我们甚至都没有办法提供足够的数据来组成一个合适的验证集。那这个问题有一个比较流行的解决方法，就是K折的交叉验证。在这里，原始的训练数据被拆分成K个不重叠的子集，然后进行K次模型训练和验证。每次在（k-1）个子集上进行训练，并在剩余的一个子集上进行验证。最后，通过对K次实验的结果取平均值来估计训练和验证的误差。简单来说，就是把以整个数据集划分成很多份，把这几个份数当中拿一份出来做验证集，剩下的全部拿来训练，然后再通过多次的训练和验证，得到一个平均的结果。最后用这个结果作为这个这这个结果出来的模型，用于评估模型和选择超参数。
说了这么多，大家都能够看出来了，如果我们想基于训练数据做一些研究的话，那么我们将尽可能地让训练误差和验证误差减小。但是训练误差和验证误差之间的差别就是我们值得讨论的一个点，这就是我们要讲的欠拟合和过拟合。
欠拟合：当训练误差和验证误差都很大的时候，就代表这个模型根本没有能力去提取这个类别的特征，说明这是一个欠拟合的情况。
过拟合：如果我们的训练误差非常小，但是我们的验证误差比较大，就说明这个数据它已经严重地，过分地拟合了这一块数据。也就是我们说的，他可能记住了整个训练集，但是没有泛化的能力。
事实上来说，欠拟合和过拟合还和模型的复杂度有关。
举一个直观的例子，比如说我们一个函数比较完美的拟合是一个二阶多项式，但是你使用了3阶甚至更高阶的多项式函数去拟合这个函数的话，那么它的训练误差应该是更低的，但是这就更有可能导致过拟合。同理，如果你只用一个1阶多项式去拟合这个函数的话，它就更有可能导致欠拟合。数据集的大小也是一个影响因素。如果数据集的样本过少，我们就有可能很有可能概率更大的过拟合。如果训练数据增加的话，我们的泛化误差通常没有那么大。一般来说，大数据不会有什么坏处。如果给出更多的数据，我们可能会尝试拟合一个更复杂的模型。如果没有足够的数据，我们可能会尝试拟合一个简单的模型。
从上述所有内容，我们其实可以看出来：大的数据集，尽可能简单的模型拟合的效果与我们所期待的实际效果非常接近。这也是我们做深度学习的目标，尽可能简洁的实现最好的学习效果，并让模型尽量不失去泛化能力。

讲到这里其实很难避开正则化之类的内容，我觉得这些内容本质上都是为了产生最佳拟合而服务的。所以其实有必要介绍介绍。
一般来说，我们的正则化最常用的就是weight decay 也就是权重衰减方式。
以线性拟合为例子，线性拟合就是给每个特征加一个特征参数w，然后根据梯度下降方法让loss函数最小。但是如果一味地追求loss最小，有可能导致w极端的大，数值稍微变动一点输出就变动很大，这个情况就类似于过拟合。那我们应该限制一下过大的w，让线性回归尽可能平滑的拟合数据集，去可能缺少一点对训练集来说没那么真实，却真正能接近泛化的能力。
给loss项加上有关w的L_2范数（的平方，为了去掉根号），在前头引入一个大于零超参数lambda用来表示对数据约束的强度。

再推一步：w := (1 - ηλ)w - η * (∂J / ∂w)      η ：learning rate（学习率）；λ ：regularization coefficient（正则化系数）；∂J / ∂w ：loss 对参数 w 的梯度
这里的意思就是，让这个w就算再怎么偏离都不要距离原点太远了，这样就比较难出现那种某一个特征对整体影响过分大的情况。
由于这里用的是L_2范数，故称为L_2正则化。
有L_2就必然有L_1。L_1就是用L_1范数做正则化。但再经过数学推导可以发现：L_1正则化的惩罚项求导之后是一个sign（）函数，把w统统往原点去靠近。所以，对于一些很小很小的参数，直接就变成0。
L1就比较适合做一些特征选择，筛选出真正有影响的特征，对其他特征直接废弃。这也称为他的稀疏性。暂时没想好它的应用哈哈哈
一般来说，L2正则化应用更广泛一点。然后就是，偏置项基本不做正则化。正则化能够比较有效的抑制过拟合。
回到神经网络中，由于神经网络拟合的复杂性，通常情况下要利用线性回归做出完美拟合还是不大可能的，因为线性回归通常不考虑特征的交互作用。正则化在这种情况下就出现更大的作用。因为前面我们说过，复杂的模型更容易出现过拟合，正则化可以很好的抑制这个情况。
这里有需要引入一个概念：偏差-方差权衡（bias-variance tradeoff），这个是有关于泛化性和灵活性之间的这种基本权衡的描述。线性模型偏差很高，只能表示一小类函数。 然而，这些模型的方差很低：它们在不同的随机数据样本上可以得出相似的结果。而神经网络并不局限于单独查看每个特征，而是学习特征之间的交互。 他们位于B-V权衡的两端，一个在不同场景下都可靠，一个偏向全面的思考。
根据前面的讨论，一个好的模型应该是：尽可能简单的，具有强大预测能力的模型。但是日常生活中遇到的数据基本都带有噪音。过拟合的一个很大原因，就是模型过分的考虑了这些噪音，导致把无论是特征还是噪点都记住了。所以，就有人提出想要在训练过程中对数据插入噪音，来培养抗噪音的能力，这从表面来看就是丢掉了一点神经元，小幅度破坏了全连接层。给我的感觉有点像变异了...这里我觉得我看到的教程讲的真的很好。原文如下：
