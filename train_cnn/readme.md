接下来就到了我这次用的理论解释。
CNN本质上就是提取图像的特征，然后通过卷积和池化让这个特征越来越明显，从而减小图片的尺度，突出它的特征，让机器能够记住它的特征，从而实现分类。
CNN在刚刚输入的时候，其实提取的边缘纹理都是没那么重要、比较泛化的特征。到后面才会提取更复杂的特征，这是通过一系列数学运算来实现的。这一系列数学运算就是卷积和池化。
卷积层涉及输入通道、输出通道、卷积核、步长还有padding五个过程。这五个过程大部分都写在我的代码注释里面了，这里就简单再回顾一下。
输入通道是指输入几张特征图。如果是RGB的特征图，基本上就是三个通道。输出通道就是经过处理之后，希望输出几张特征图。
以下是有关卷积层大小计算的公式：
H_out = (H_in - K + 2P) / S + 1
W_out = (W_in - K + 2P) / S + 1
其中：
H_in  : 输入高度
K     : 卷积核大小
P     : padding
S     : stride
这里有一个挺有意思的地方。拿第一层卷积层来说，它有三个输入特征图，但是却有16个输出特征图，这是怎么做到的？
三个输入特征图经过卷积核分别卷积之后，再叠加，就得到了一张输出特征图。而经过16次相似的运算之后，就能得到16张相似但不相同的输出特征图。
随着网络的加深，我们不再需要特别高的空间分辨率，反而需要更多的语义特征来进行分类。所以说，用池化压缩尺寸，用卷积增加通道，这就是CNN的核心思想之一。
BatchNorm2d其实就是对卷积层输出的数据进行标准化处理。因为深度学习过程中，不同层输出的数据分布可能会不断发生变化。如果数据变化太剧烈，网络训练就会变得很不稳定，学习率也不好调。所以用这个函数就可以在一个batch的数据上先计算均值和方差，再把数据调整到一个相对稳定的分布附近。他的公式：
x_hat = (x - mean) / sqrt(var + eps)     y = gamma * x_hat + beta
这样做的好处就是可以让网络训练更加稳定，同时加快收敛速度，在一定程度上缓解梯度消失或者梯度爆炸这种问题。
在我的网络中，我把这个东西放在卷积层后面、激活函数前面。这样卷积层输出的数据会先进行标准化，再进入激活函数。由于数据分布更加稳定，所以后面激活函数输出不会因为数值过大或者过小而波动太明显。
还没有做对比实验，因为在上次机器学习过程当中，我就意识到对数据进行标准化是比较重要的。所以这次我还特地搜索了深度学习当中要怎么做标准化。然后就得到了这个方法。
从输出的数据来看，loss非常小，而且在学习率比较大的情况下，可以预见这个函数对于训练稳定性的帮助还是比较明显的。
激活函数我用ReLU，因为这个函数比较经典。能增加非线性，大于零的话就是原函数，小于零的话就直接消失。使用它是因为这个函数的性质比较经典，不容易出错。用别的话我没有把握能够调得很好，但是其实我之后还是想试一下，如果换成其他函数会有什么不同，这个就等之后再说吧！
池化层的话就比较好理解了。池化层其实就是压缩尺寸、突出特征。你看我们输入的图最开始是规定为64×64的一张RGB三通道图，到最后池化层池化三层之后，它变成了一张8×8的图。这个时候它的特征就比较突出了。
变化是这样的：64x64 -> 32x32 -> 16x16 -> 8x8
空间尺寸越来越小，但特征越来越明显
网络的整体结构
| 层     | 输入尺寸     | 输出尺寸     |
| ----- | -------- | -------- |
| Conv1 | 3×64×64  | 16×32×32 |
| Conv2 | 16×32×32 | 32×16×16 |
| Conv3 | 32×16×16 | 64×8×8   |
| FC    | 4096     | 3        |
首先是作业的要求。作业要求全连接层不能超过三层，总层数不超过十层，所以这个神经网络就没有设计得很深。而且这个数据集确实不大，利用三层卷积已经能很好地提取特征。继续增加的话，参数量会过大，感觉不太适合我们这次作业的强度。
在数据的导入和预处理上，我对数据采用了RandomHorizontalFlip，让数据进行随机的左右翻转，提高数据的多样性，防止过拟合。同时也能提高整个模型的泛化能力。
现在就是学习策略的选择。我选择用MBGD，它既能够有效避免SGD单样本更新波动大的缺点，也能够有效避免BGD全数据更新很慢的缺点。选择MBGD，也是因为GPU利用率能到一个合理的范围。
MBGD不只是训练一个batch，它是把训练集拆分成很多个batch，每个epoch仍然会遍历全部数据。自然地，在数据输出上就不能够再把对batch的测试放在epoch里面。这样测试次数会变得非常多，特别消耗计算机资源，也会大大提高时间复杂度，可能在时间上就没那么优秀了。
